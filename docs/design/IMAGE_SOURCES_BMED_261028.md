## 검색 키워드(영문)

## 사용 규칙
1. 본문 주제와 직접 관련된 이미지만 쓴다. 시술 효과·전후 비교로 오해될 사진, 특정 브랜드·제품·클리닉 로고가 보이는 사진은 쓰지 않는다.
2. 사람이 나오는 사진은 실제 환자·본인 후기로 오해되지 않게 캡션에 "stock photo"를 밝힌다.
3. 출처(사이트·작가·사진 URL·라이선스·확인 시각)를 `.source.txt`에 남긴다. 캡션에도 한 줄로 밝힌다.
4. Instagram 비율 4:5~1.91:1, 가로 1080px 이상으로 맞춘다(자르거나 흰 여백 패딩, 내용 변형 없음).
5. 이미지 확보 순서: ①이 문서의 무료 사이트 ②Wikimedia Commons(CC0/CC-BY/PD) ③AI 생성(`image_style="diagram"`).
